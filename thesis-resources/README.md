# Thesis Resources

This directory contains supporting resources used during the development of the **InTheBag** application. These are not part of the main frontend or backend codebases but were essential for preparing the data and validating the system.

### Included Materials

- Data scraping script (`scrape.js`)
- Data preprocessing notebooks
- Suggestion dataset generation
- Exploratory testing files
- Supporting data file: `plastics.txt`

### Notes

The notebooks were created in **Google Colab** and use **custom directory paths** (e.g., `/content/drive/...`). If you plan to run these notebooks yourself, make sure to adjust the paths to fit your environment.

The dataset used for preprocessing (`discs.csv`) is generated by running `scrape.js`. The `plastics.txt` file is manually created and required by the preprocessing step.

### Process Overview

To recreate the full data preparation and suggestion logic, follow this order:

1. Run `scrape.js` to generate `discs.csv`
2. Run the preprocessing notebook(s)
3. Run the suggestion dataset generation notebook
